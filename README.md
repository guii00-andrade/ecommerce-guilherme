# 🛒 E-commerce Flask

Sistema de e-commerce desenvolvido com Python, Flask e SQLite como projeto de portfólio para estudos em desenvolvimento web.

## 📌 Sobre o projeto

O projeto simula uma loja virtual com funcionalidades de cliente e administrador.

O objetivo é aplicar na prática conceitos de desenvolvimento web, programação em Python, banco de dados e autenticação de usuários.

## 🚀 Funcionalidades

### Cliente
- Cadastro de usuário
- Login e logout
- Visualização de produtos
- Página individual do produto
- Carrinho de compras
- Alteração da quantidade de produtos
- Remoção de produtos do carrinho
- Checkout
- Registro de pedidos

### Administrador
- Login administrativo
- Visualização dos produtos
- Visualização dos pedidos
- Cadastro de novos produtos

## 🛠️ Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2
- Git
- GitHub
